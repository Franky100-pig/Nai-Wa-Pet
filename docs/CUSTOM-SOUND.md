# 自定义声音

内置的音效都是 WebAudio 现场合成的，能听，但肯定不如原声。你可以用自己的音频替换掉，
**不用改代码，也不用重新打包**。

## 30 秒版

1. 右键点桌宠 →「换声音…」，会打开一个 `sounds` 文件夹
2. 把音频文件丢进去，改名成 `laugh.mp3`
3. 再右键一次桌宠（把菜单开一下再关掉），完事

## 四个槽位

文件名对上下面的名字就行，扩展名 `mp3` / `m4a` / `wav` / `ogg` / `aac` 任选：

| 文件名 | 什么时候响 |
|---|---|
| `laugh.*` | 菜单里点「笑一个」 |
| `poke.*` | 用左键点它一下 |
| `land.*` | 从手上掉到桌面那一下 |
| `feed.*` | 菜单里点「喂奶茶」 |

只换一个也行，比如只有 `laugh.mp3`，其余三个继续用合成音。

## 文件夹在哪

正常情况下点「换声音…」就自动打开了，不用背路径：

```
macOS（从 DMG 装的）   ~/Library/Application Support/奶蛙桌宠/sounds/
macOS（npm start）     ~/Library/Application Support/naiwa-pet/sounds/
Windows                %APPDATA%\naiwa-pet\sounds\
```

第一次运行会自动建目录，并在里面放一份 `说明.txt`。

> 为什么不在 `.app` 里面？因为 `.app` 是签过名的，往包里塞文件会让签名失效，
> 在 Apple Silicon 上可能就启动不了了。所以音频放用户目录，升级 App 也不会丢。

## 音频从哪来

- **爱给网**有现成的：<https://www.aigei.com/sound/class/nai_long_d/>
  里面是「奶龙大笑」「【抽象】奶龙捧腹大笑-原版+变声」
- **从视频里抠音轨**。手机存的视频也能用，转成 mp3 或 m4a 就行：

  ```bash
  # 有 ffmpeg 的话（最省事）
  ffmpeg -i 素材.mp4 -vn -ac 2 -b:a 128k laugh.mp3

  # 没有 ffmpeg，用 macOS 自带的 afconvert 转成 m4a
  afconvert -f m4af -d aac -b 128000 素材.wav laugh.m4a
  ```

- **QuickTime Player** 也能干：打开视频 → 文件 → 导出为 → 仅音频，出来是 `.m4a`，直接用。

## 时长

「笑一个」的动画时长是跟着音频长度走的（夹在 1.4 秒到 7 秒之间）。
太短会一闪而过，建议裁到 **2～5 秒**，正好是它笑完一轮。

## 没生效？按这个顺序查

1. **文件名**：全小写、没有空格、扩展名没写错（`laugh.mp3` 不是 `Laugh.MP3` 也不是 `laugh.mp3.mp3`）
2. **文件太小**：小于 1KB 会被当成空文件跳过
3. **没触发重扫**：开一次菜单再关掉，或者干脆重启 App
4. **静音了**：菜单里看看「声音：开」还是「关」
5. **目录不对**：菜单「换声音…」打开的那个才是真正生效的目录
