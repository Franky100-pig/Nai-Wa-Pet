把音频文件丢进这个文件夹，文件名对上就能替换掉内置的合成音。

四个槽位（扩展名 mp3 / m4a / wav / ogg / aac 都行，任选一个）：

  laugh.*   笑一个（右键菜单里点了会播）
  poke.*    点它一下
  land.*    从手里掉到桌面上那一下
  feed.*    喝奶茶

举例：想要自己的笑声，就放一个 laugh.mp3 进来。

不用改代码，也不用重启：存好文件后，右键点桌宠打开菜单再关掉，
它会自动重扫一遍，之后就生效了。

去哪找？
  · 爱给网有「奶龙大笑」「【抽象】奶龙捧腹大笑-原版+变声」：
    https://www.aigei.com/sound/class/nai_long_d/
  · 或者从视频里扣一段，用 QuickTime / ffmpeg 转成 mp3

注意：
  · 文件要大于 1KB，太小的会被当成空文件跳过
  · 名字全小写，别加空格
  · 这些音频版权不属于你，只在自己电脑上用，别跟着代码一起发布
